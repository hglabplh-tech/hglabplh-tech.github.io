# Sponsor HGPPascal

Thank you for considering sponsoring **HGPPascal**!

HGPPascal is an independent open-source Pascal compiler written in Clojure that targets **C99**, **JVM bytecode**, and **Pascal P-Code**. The project combines modern compiler architecture with Turbo Pascal compatibility goals while remaining a clean-room implementation.

## Why Sponsor?

Your sponsorship helps fund:

- Turbo Pascal compatibility improvements
- New compiler optimizations
- Native backend research
- Better diagnostics
- Documentation and tutorials
- CI infrastructure and testing
- Long-term maintenance

- Improve documentation
- Submit pull requests
- Share HGPPascal with others
- Create example projects

Every contribution helps move HGPPascal toward becoming one of the most complete modern open-source Pascal compilers.
