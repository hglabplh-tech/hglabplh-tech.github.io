# HGPPascal: A Turbo Pascal-Inspired Compiler Research Platform

**ABSTRACT:** HGPPascal is a modern compiler project for a Turbo Pascal-style language with C, P-Code, JVM, and native executable backends.
It explores classic compiler construction through a modular lexer, parser, AST, descriptor model, runtime, and optimization pipeline.
The project includes SECD/SSTD runtime concepts, functional lambdas, object support, heap management, and numeric compute facilities.
It aims to serve as both a practical Pascal compiler and a research-friendly foundation for studying language design, runtimes, and backend generation.
