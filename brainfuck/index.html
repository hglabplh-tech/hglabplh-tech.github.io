This project is a little language I defined in one day. The language is compiled to BrainFuck [trade mark] ;-)

I made this project because I am fascinated by the BrainFuck language. It is a 'crazy' language. But of course you can code many things with it, and it is Turing Complete.

/* A system is Turing complete if it can solve any computational problem that a theoretical Alan Turing machine can solve. */

Brainfuck has a interrestng history and it is a language to show that a turing complete language does not need a complex set of mnemnonics or commands keywords and so on. Brainfuck is absolute minimalistic. My little Language shows that it is possible to compile a higher level language to Brainfuck that means Brainfuck has all components needed for computing in a way that a Turing Complete language can be compiled to Braifuck. My Little language is up to now not complete but it is nearly complete and I think it works correct. What I will do is to check the output with a well known BrainFuck Compiler / Interpreter.
