# PL1CompInPy: A Python-Based PL/I Compiler and Learning Runtime 

**ABSTRACT:** PL1CompInPy is an educational compiler project that explores PL/I parsing, AST construction, semantic analysis, runtime services, and multi-target code generation in Python. It supports core PL/I language features including procedures, control flow, declarations, structures, pointers, builtins, file I/O, VSAM-style datasets, and numeric computation. The project includes experimental backends for Python source, JVM bytecode, .NET IL, native assembler, and binary container formats such as PE, ELF, and Mach-O. It is designed for students, researchers, and compiler enthusiasts who want to study how to model, bootstrap, and gradually compile a classic systems language across modern platforms.
