# A short word about `active-data`, which is referenced in our project

Mike Sperber (Active Group) and others initiated the `active-data` project.
We're interested in using his approach to creating contracts for functions, records, and other data used in the program. This part of active data is used if the product uses it to get a clear reflection about function and record typing.
